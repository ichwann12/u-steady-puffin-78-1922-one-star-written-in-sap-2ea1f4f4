## The entry

> One star. My owner waters me when he remembers, which is never, then blames me for dying. The sunlight here is a rumor. Would not recommend this human.

The full entry text lives in `entry.txt`.

## Run

```sh
node main.ts
```

`main.ts` reads `entry.txt` and writes it to the output directory given by
the `MAKEFUN_BOT_DIR` / `MAKEFUN_OUTPUT_DIR` environment variables
(defaulting to `./output`). Node 22, standard library only — no network,
no wall clock, deterministic output.
